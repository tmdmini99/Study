
피보나치 수는 F(0) = 0, F(1) = 1일 때, 1 이상의 n에 대하여 F(n) = F(n-1) + F(n-2) 가 적용되는 수 입니다.
```java
F(1) = 1  
F(2) = 1  
F(n) = F(n-1) + F(n-2)  (n ≥ 3)
```
즉, 앞의 두 수를 더해서 다음 수를 만드는 구조예요.


이 함수는 **"n번째 피보나치 수"** 하나를 구하는 함수입니다.

```java
public int re(int n) {
    if (n == 1 || n == 2) return 1;
    return re(n - 1) + re(n - 2);
}
```
반복문 알고리즘

```java
int fib(int n) {
    int a = 1, b = 1;
    for (int i = 3; i <= n; i++) {
        int temp = a + b;
        a = b;
        b = temp;
    }
    return b;
}

```
