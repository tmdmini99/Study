
재귀 알고리즘(Recursive Algorithm)은 **함수가 자기 자신을 호출해서 문제를 푸는 방법**입니다. 작고 동일한 구조의 하위 문제들로 문제를 나누는 **분할 정복(Divide and Conquer)** 기법과도 관련이 깊습니다


## 재귀 알고리즘의 핵심 개념

1. **기저 조건(Base Case)**
    
    - 재귀 호출을 멈추기 위한 조건입니다.
        
    - 없으면 무한 반복(→ StackOverflowError 발생)
        
2. **재귀 호출(Recursive Case)**
    
    - 문제를 더 작게 쪼개어 자기 자신을 다시 호출합니다.


 팩토리얼 (Factorial)

```java
int factorial(int n) {
    if (n == 0) return 1;           // 기저 조건
    return n * factorial(n - 1);    // 재귀 호출
}
```
예: `factorial(3) = 3 * factorial(2) = 3 * 2 * 1 = 6`

피보나치 수열

```java
int fibonacci(int n) {
    if (n == 1 || n == 2) return 1;         // 기저 조건
    return fibonacci(n - 1) + fibonacci(n - 2);  // 재귀 호출
}
```
