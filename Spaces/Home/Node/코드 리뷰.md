
gateway-server구조
```bash
src/
├── auth/                      ← JWT 인증 관련
│   ├── auth.module.ts
│   ├── jwt.strategy.ts
│   ├── jwt-auth.guard.ts
│   ├── roles.guard.ts
│   ├── roles.decorator.ts
├── gateway/
│   ├── gateway.controller.ts  ← 요청 받는 컨트롤러
│   ├── gateway.module.ts
│   └── gateway.service.ts     ← 라우팅 or 유틸 서비스
├── main.ts                    ← 그대로 유지
```


auth-server 구조
```bash
auth-server/
├── src/
│   ├── auth/
│   │   ├── auth.controller.ts        ← 로그인 및 인증 관련 API
│   │   ├── auth.service.ts           ← 인증 관련 비즈니스 로직 처리
│   │   ├── auth.module.ts            ← Auth 모듈의 루트 모듈
│   │   ├── jwt.strategy.ts           ← JWT 검증 전략 (passport와 함께 사용)
│   │   ├── jwt-payload.interface.ts ← JWT Payload 인터페이스 정의
│   │   └── dto/
│   │       └── login.dto.ts          ← 로그인 요청을 위한 DTO (새로 추가)
│   ├── users/
│   │   ├── user.schema.ts            ← MongoDB 유저 스키마
│   │   ├── users.service.ts          ← 사용자 관련 비즈니스 로직
│   │   └── users.module.ts           ← Users 모듈
│   ├── database/
│   │   └── database.module.ts       ← MongoDB 연결 설정
│   ├── config/
│   │   └── default.ts               ← 기본 환경설정 (옵션)
│   ├── main.ts                      ← 애플리케이션 부트스트랩 파일
│   └── app.module.ts                ← 루트 모듈
├── .env                             ← 환경 설정 파일
├── package.json
└── tsconfig.json

```

터미널에 밑에 명령어 입력시 로그인 성공 실패 여부 반환

```bash
curl -X POST http://localhost:3000/auth/login \

  -H "Content-Type: application/json" \

  -d '{"username": "john Doe", "password": "password"}'
```
