

## 원형 수열 (Circular Sequence)이란?

---

### 1. 기본 개념

- 일반 수열은 시작과 끝이 명확하게 구분되어 있어요.  
    예: `[1, 2, 3, 4, 5]`  
    시작은 1, 끝은 5.
    
- **원형 수열**은 이 수열이 **끝과 다시 연결되어 원형(원처럼)으로 이어져 있다**고 생각하는 것.
    

즉,  
마지막 원소 다음이 다시 첫 번째 원소로 연결됨

---

### 2. 예시

수열: `[1, 2, 3, 4, 5]` 를 원형으로 생각하면,

- 5 다음에는 다시 1이 온다고 생각
    
- 수열이 무한히 계속 이어지는 느낌
    

---

### 3. 원형 수열의 특징

- 인덱스가 `n`을 넘어가면 다시 0으로 돌아감 (모듈로 연산 활용)  
    예: `arr[(i + 1) % n]`
    
- 자주 쓰이는 분야:
    
    - 링 버퍼 (Ring buffer)
        
    - 원형 큐 (Circular queue)
        
    - 시계 방향 순회 문제 등
        

---

### 4. 원형 수열과 관련된 문제 유형

- 수열의 연속된 구간 찾기 (구간이 원형으로 연결되어 있음)
    
- 회전 배열 (Rotated array)
    
- 원형 배열에서 최대/최소 구간 찾기
```java
int[] arr = {1, 2, 3, 4, 5};
int n = arr.length;

for (int i = 0; i < n; i++) {
    int nextIndex = (i + 1) % n; // 원형 인덱스
    System.out.println(arr[i] + " 다음은 " + arr[nextIndex]);
}

```

원형 수열에서 연속하는 부분 수열의 합으로 만들 수 있는 수가 모두 몇 가지인 알아보는 코드

```java
import java.util.*;
class Solution {
    public int solution(int[] elements) {
        int answer = 0;
        Set<Integer> set = new HashSet<>();
        for (int i = 0; i < elements.length; i++) {
            int sum = 0;
            for (int len = 1; len <= elements.length; len++) {
                int idx = (i + len - 1) % elements.length;
                sum += elements[idx];
                set.add(sum);
            }
        }
        return answer = set.size();
        
    }
}
```
