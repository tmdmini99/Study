



```java
int n = 3;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        arr[i][j] = Math.max(i, j) + 1;
    }
}
```

| i (행) | j (열) | max(i, j) | arr[i][j] = max(i, j) + 1 |
| ----- | ----- | --------- | ------------------------- |
| 0     | 0     | 0         | 1                         |
| 0     | 1     | 1         | 2                         |
| 0     | 2     | 2         | 3                         |
| 1     | 0     | 1         | 2                         |
| 1     | 1     | 1         | 2                         |
| 1     | 2     | 2         | 3                         |
| 2     | 0     | 2         | 3                         |
| 2     | 1     | 2         | 3                         |
| 2     | 2     | 2         | 3                         |


```java
arr = [
  [1, 2, 3],   // i = 0
  [2, 2, 3],   // i = 1
  [3, 3, 3]    // i = 2
]
```

즉, 각 원소는 `i`와 `j` 중 **큰 값에 +1**을 한 숫자입니다.

- `arr[0][2]`: max(0, 2) + 1 = 2 + 1 = 3
    
- `arr[2][0]`: max(2, 0) + 1 = 2 + 1 = 3
    
- `arr[1][1]`: max(1, 1) + 1 = 1 + 1 = 2

|개념|의미|
|---|---|
|`i`|행 인덱스 (0부터 시작)|
|`j`|열 인덱스 (0부터 시작)|
|`arr[i][j] = max(i, j) + 1`|큰 인덱스에 1을 더한 값|
|전체 배열을 구성하는 규칙|각 칸마다의 (i, j)를 가지고 계산하면 됨|
