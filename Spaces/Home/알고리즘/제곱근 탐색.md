약수 구하기

```java
class Solution {
    public int solution(int number, int limit, int power) {
        int answer = 0;

        for (int i = 1; i <= number; i++) {
            int count = 0;
            for (int j = 1; j * j <= i; j++) {
                if (i % j == 0) {
                    count += (j * j == i) ? 1 : 2;
                }
            }
            if (count > limit) {
                count = power;
            }
            answer += count;
        }

        return answer;
    }
}

```

약수는 보통 쌍으로 존재 하지만 제곱근의 경우는 한개만 존재


예를 들어,  
`n = 36`이라면 약수 쌍은:

- (1, 36)
    
- (2, 18)
    
- (3, 12)
    
- (4, 9)
    
- (6, 6) ← **여기서 6은 중복된 약수**
    

보면, `6 * 6 = 36`, 즉 **제곱수**가 되는 경우가 중복 없이 **한 번만 세야 해요.**

```java
class Solution {
    public int solution(int left, int right) {
        int answer = 0;

        for (int i=left;i<=right;i++) {
            //제곱수인 경우 약수의 개수가 홀수
            if (i % Math.sqrt(i) == 0) {
                answer -= i;
            }
            //제곱수가 아닌 경우 약수의 개수가 짝수
            else {
                answer += i;
            }
        }

        return answer;
    }
}
```

### 제곱수는 약수의 개수가 홀수인가?

**모든 자연수는 약수를 짝수 개 가지지만,**  
**제곱수는 자기 자신을 곱한 수(예: 6×6=36)가 있기 때문에 약수 개수가 홀수 개가 됩니다.**



```java
i % Math.sqrt(i) == 0
```

만약 `i`가 제곱수라면,  
`Math.sqrt(i)`는 정수이고,  
`i % 정수 == 0` → 나머지가 0이므로 조건은 `true`.

---

### 🔧 예시

#### 예 1: `i = 36`

- `Math.sqrt(36) = 6.0`
    
- `36 % 6.0 == 0` → `true`
    

✔️ 36은 제곱수 → 조건 만족

---

#### 예 2: `i = 10`

- `Math.sqrt(10) ≈ 3.16...` (정수가 아님)
    
- `10 % 3.16... ≠ 0` → `false`
    

❌ 10은 제곱수가 아님 → 조건 불만족


## 소수 구하기

기본적인 소수 판별문

```java
public static boolean isPrime(int n) {
    if (n < 2) return false; // 0, 1은 소수가 아님
    for (int i = 2; i <= Math.sqrt(n); i++) {
        if (n % i == 0) return false; // 나누어 떨어지면 약수가 있으므로 소수 아님
    }
    return true;
}

```

- `Math.sqrt(n)`까지만 검사하는 이유:  
    n의 약수가 `√n` 넘는 수부터는 짝이 이미 아래쪽에 있기 때문이에요.
    
- 예: 12 = 3 × 4 → √12보다 큰 수(4)는 이미 3과 짝을 이룸


N까지의 모든 소수를 구하는 방법 (에라토스테네스의 체)

```java
public static List<Integer> getPrimes(int n) {
    boolean[] isPrime = new boolean[n + 1];
    Arrays.fill(isPrime, true);
    isPrime[0] = false;
    isPrime[1] = false;

    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }

    List<Integer> primes = new ArrayList<>();
    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) primes.add(i);
    }
    return primes;
}

```


좋습니다! 이 코드는 주어진 정수 배열 `nums`에서 서로 다른 3개의 수를 더한 값이 **소수인지** 판별하고, 그런 소수 조합의 개수를 세는 문제를 해결하는 코드입니다.

```java
import java.util.*;
class Solution {
    public int solution(int[] nums) {
        int answer = 0;
        for(int i=0; i<nums.length; i++){
            for(int j=i+1; j<nums.length; j++){
                for(int k=j+1; k<nums.length; k++){
                    int sum = nums[i]+nums[j]+nums[k];
                    for(int l = 2; l<Math.sqrt(sum); l++){
                        if (sum % l == 0) {
                            break; 
                        }
                        if (l == (int)Math.sqrt(sum)) {
                            System.out.println("sum : " + sum);
                            answer++;
                        }
                    }
                        
                }   
            }    
        }

        return answer;
    }
}
```

- 왜냐하면 **약수가 존재한다면 반드시 √n 이하 중 하나는 약수이기 때문**임.

### 왜 sqrt까지만 확인하면 되는가?

예를 들어 어떤 수 `n = 30`이 있다고 할 때,

- `30 = 2 × 15`
    
- `30 = 3 × 10`
    
- `30 = 5 × 6`
    

→ 약수는 항상 **한 쌍**으로 존재해요. 하나가 크면, 다른 하나는 작아요.

즉, **작은 약수 ≤ sqrt(n)** 이기 때문에, 그 범위까지만 체크하면 소수 여부를 정확히 판별할 수 있어요.


|항목|설명|
|---|---|
|`Math.sqrt(n)`|`n`의 제곱근을 반환 (`double` 타입)|
|소수 판별 시 이유|√n 이하까지만 나눠보면 소수 여부를 판단할 수 있음|
|예시|`n = 29`이면 `2~5`까지만 나눠보면 충분|
