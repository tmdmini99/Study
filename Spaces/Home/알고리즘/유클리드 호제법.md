## 유클리드 호제법이란?

- **두 수의 최대공약수(GCD)를 구하는 알고리즘**입니다.
    
- **기본 아이디어**는:  
    두 수 a,ba, ba,b (단, a>ba > ba>b)의 최대공약수는  
    gcd⁡(a,b)=gcd⁡(b,a  b)\gcd(a, b) = \gcd(b, a \bmod b)gcd(a,b)=gcd(b,amodb)와 같다는 점이에요.
    
- 즉, 큰 수에서 작은 수를 나눈 나머지로 계속 재귀 또는 반복해서 최대공약수를 찾는 거죠.
    

---

## 왜 이게 맞을까?

- aaa와 bbb를 동시에 나누는 수는 bbb와 a  ba \bmod bamodb도 동시에 나눕니다.
    
- 그래서 최대공약수는 둘 다 나누는 가장 큰 수이므로, gcd⁡(a,b)=gcd⁡(b,a  b)\gcd(a, b) = \gcd(b, a \bmod b)gcd(a,b)=gcd(b,amodb)가 성립합니다.
    

---

## 간단한 예시

- gcd⁡(48,18)\gcd(48, 18)gcd(48,18) 구하기
    
    gcd⁡(48,18)=gcd⁡(18,48  18)=gcd⁡(18,12)\gcd(48, 18) = \gcd(18, 48 \bmod 18) = \gcd(18, 12)gcd(48,18)=gcd(18,48mod18)=gcd(18,12) =gcd⁡(12,18  12)=gcd⁡(12,6)= \gcd(12, 18 \bmod 12) = \gcd(12, 6)=gcd(12,18mod12)=gcd(12,6) =gcd⁡(6,12  6)=gcd⁡(6,0)=6= \gcd(6, 12 \bmod 6) = \gcd(6, 0) = 6=gcd(6,12mod6)=gcd(6,0)=6
- 나머지가 0이 되면 그때의 수가 최대공약수입니다.

## 요약

- **유클리드 호제법**은 **최대공약수(GCD)를 구하는 효율적인 알고리즘**입니다.
    
- 큰 수를 작은 수로 나눈 나머지를 이용해 반복/재귀적으로 문제를 작게 만듭니다.
    
- 실제로 프로그래밍에서 최대공약수 구할 때 가장 많이 사용해요.


```java
public static int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}
```

|---|---|---|---|
|1|48|18|`temp = b = 18`|
||||`b = a % b = 48 % 18 = 12`|
||||`a = temp = 18`|
|2|18|12|`temp = 12`|
||||`b = 18 % 12 = 6`|
||||`a = 12`|
|3|12|6|`temp = 6`|
||||`b = 12 % 6 = 0`|
||||`a = 6`|
|종료|6|0|`b`가 0이므로 반복 종료, 결과는 `a = 6`|



## 최소공배수와 유클리드 호제법의 관계

- 두 수 aaa와 bbb의 최대공약수(GCD)를 먼저 구하고 나서,
    
- 다음 공식을 이용해서 최소공배수를 구합니다:
    

LCM(a,b)=a×bGCD(a,b)\text{LCM}(a,b) = \frac{a \times b}{\text{GCD}(a,b)}LCM(a,b)=GCD(a,b)a×b​

---

## 왜 이런 공식이 성립하는가?

- aaa와 bbb의 최대공약수가 ddd라 하면,  
    a=d×ma = d \times ma=d×m, b=d×nb = d \times nb=d×n이고, mmm과 nnn은 서로소입니다.
    
- 최소공배수는 d×m×nd \times m \times nd×m×n인데, 이 값이 a×bd\frac{a \times b}{d}da×b​와 같아요.
    
- 그래서 최대공약수를 이용해 최소공배수를 효율적으로 구할 수 있습니다.
    

---

## 자바 코드 예시


```java
public static int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

public static int lcm(int a, int b) {
    return (a * b) / gcd(a, b);
}
```

- 먼저 최대공약수를 구한다.
    
- 두수를 곱한 후 최대공약수로 나누면 최소공배수가 된다.
  12×18=216 을 최대공약수 6으로 나누면 36이 나와 최소공배수.



## 재귀 함수를 이용

```java
import java.util.Arrays;

class TryHelloWorld {
    // gcd와 lcm을 구해서 배열로 반환하는 메서드
    public int[] gcdlcm(int a, int b) {
        int[] answer = new int[2];  // 결과를 담을 배열 (크기 2)

        answer[0] = gcd(a, b);       // 최대공약수 (gcd) 저장
        answer[1] = (a * b) / answer[0];  // 최소공배수 (lcm) 저장
        return answer;               // 배열 반환
    }

    // 유클리드 호제법으로 최대공약수 구하는 재귀 함수
    public static int gcd(int p, int q) {
        if (q == 0) return p;         // q가 0이면 p가 최대공약수
        return gcd(q, p % q);          // q가 0이 아니면 재귀 호출 (p % q가 나머지)
    }

    // main 함수 - 테스트용
    public static void main(String[] args) {
        TryHelloWorld c = new TryHelloWorld();
        System.out.println(Arrays.toString(c.gcdlcm(3, 12)));
    }
}
```


두 수의 최대공약수를 구한 후 최소 공배수 구하기
```java
class Solution {
    public int[] solution(int n, int m) {
        int[] answer = new int[2];
        int a = n > m ? n : m;
        int b = n < m ? n : m;
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        answer[0] = a;
        answer[1] = n*m / a;
        return answer;
    }
}
```



여러개의 최소공배수 구하기

- 먼저 aaa와 bbb의 최소공배수를 구하고,
    
- 그 결과와 ccc의 최소공배수를 구하고,
    
- 그 결과와 ddd의 최소공배수를 구하는 식으로 반복



```java

class Solution {
    public int solution(int[] arr) {
        int answer = arr[0];
        for(int i=1; i<arr.length; i++){
            answer = lcm(answer, arr[i]);            
        }
        return answer;
    }
    public int gcd(int a, int b){
        while(b !=0){
            int temp = b;
            b = a%b;
            a = temp;
        }
        return a;
    }
    public int lcm(int a, int b){
        return (a*b) / gcd(a,b);
    }
}
```

public long gcd(long a, long b) {
        if (a > b)
            return (a % b == 0) ? b : gcd(b, a % b);
        else
            return (b % a == 0) ? a : gcd(a, b % a);
    }
