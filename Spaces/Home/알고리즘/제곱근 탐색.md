약수 구하기

```java
class Solution {
    public int solution(int number, int limit, int power) {
        int answer = 0;

        for (int i = 1; i <= number; i++) {
            int count = 0;
            for (int j = 1; j * j <= i; j++) {
                if (i % j == 0) {
                    count += (j * j == i) ? 1 : 2;
                }
            }
            if (count > limit) {
                count = power;
            }
            answer += count;
        }

        return answer;
    }
}

```

약수는 보통 쌍으로 존재 하지만 제곱근의 경우는 한개만 존재


예를 들어,  
`n = 36`이라면 약수 쌍은:

- (1, 36)
    
- (2, 18)
    
- (3, 12)
    
- (4, 9)
    
- (6, 6) ← **여기서 6은 중복된 약수**
    

보면, `6 * 6 = 36`, 즉 **제곱수**가 되는 경우가 중복 없이 **한 번만 세야 해요.**

```java
class Solution {
    public int solution(int left, int right) {
        int answer = 0;

        for (int i=left;i<=right;i++) {
            //제곱수인 경우 약수의 개수가 홀수
            if (i % Math.sqrt(i) == 0) {
                answer -= i;
            }
            //제곱수가 아닌 경우 약수의 개수가 짝수
            else {
                answer += i;
            }
        }

        return answer;
    }
}
```

### 제곱수는 약수의 개수가 홀수인가?

**모든 자연수는 약수를 짝수 개 가지지만,**  
**제곱수는 자기 자신을 곱한 수(예: 6×6=36)가 있기 때문에 약수 개수가 홀수 개가 됩니다.**



```java
i % Math.sqrt(i) == 0
```

만약 `i`가 제곱수라면,  
`Math.sqrt(i)`는 정수이고,  
`i % 정수 == 0` → 나머지가 0이므로 조건은 `true`.

---

### 🔧 예시

#### 예 1: `i = 36`

- `Math.sqrt(36) = 6.0`
    
- `36 % 6.0 == 0` → `true`
    

✔️ 36은 제곱수 → 조건 만족

---

#### 예 2: `i = 10`

- `Math.sqrt(10) ≈ 3.16...` (정수가 아님)
    
- `10 % 3.16... ≠ 0` → `false`
    

❌ 10은 제곱수가 아님 → 조건 불만족
