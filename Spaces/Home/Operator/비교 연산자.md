| 연산자  | 설명     | 예시       | 결과         |
| ---- | ------ | -------- | ---------- |
| `==` | 같다     | `a == b` | true/false |
| `!=` | 같지 않다  | `a != b` | true/false |
| `<`  | 작다     | `a < b`  | true/false |
| `>`  | 크다     | `a > b`  | true/false |
| `<=` | 작거나 같다 | `a <= b` | true/false |
| `>=` | 크거나 같다 | `a >= b` | true/false |
|      |        |          |            |
