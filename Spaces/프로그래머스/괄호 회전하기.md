


stack을 사용하여 괄호를 >> 밀었을때 제대로 닫히는 괄호가 되는지 확인
`{}` 또는 `{{}}` , `{[]}` , `{()}` 이런식으로 되어야 함
민다는 의미 -> `"[](){}"` 에서 한칸 밀었을 때 `"](){}["` 이렇게 되어야 한다.

```java
import java.util.*;
class Solution {
    public int solution(String s) {
        int answer = 0;
        for(int i=0; i<s.length(); i++){
            String ss = s.substring(i)+s.substring(0,i);
            Stack<Character> stack = new Stack<>();
            boolean flag = true;
            for(char c : ss.toCharArray()){
                if(c == '[' || c == '{' || c == '(' ){
                    stack.push(c);
                }else{
                    
                    if (stack.isEmpty()){
                        flag = false;
                        break;
                    }
                    char stackPop = stack.pop();
                    if(stackPop== '[' && c != ']'){
                        flag = false;
                        break;
                    }else if(stackPop == '{' && c != '}'){
                        flag = false;
                        break;
                    }else if(stackPop == '(' && c != ')'){
                        flag = false;
                        break;
                    }                    
                }
            }
            if(stack.size() == 0 && flag) answer++;
            stack.clear();
        }
        return answer;
    }
}
```


```java
String rotated = s.substring(i) + s.substring(0, i);
```
위 코드를 통해서 i가 0일때

```java
s.substring(0)     → "[](){}"
s.substring(0, 0)  → ""
rotated = "[](){}" + "" → "[](){}"  ← 회전 없음
```

i가 1일때
```java
s.substring(1)     → "](){}"
s.substring(0, 1)  → "["
rotated = "](){}" + "[" → "](){}["
```
