

재귀 알고리즘(Recursive Algorithm)은 **함수가 자기 자신을 호출해서 문제를 푸는 방법**입니다. 작고 동일한 구조의 하위 문제들로 문제를 나누는 **분할 정복(Divide and Conquer)** 기법과도 관련이 깊습니다.
자기 자신을 호출해서 값을 구함

```java
import java.util.*;
class Solution {
    public int solution(int n) {
        int answer = 0;
        return re(n)%1234567;
    }
    public int re(int n) {
        if (n == 1 || n == 2) return 1;
        return re(n - 1) + re(n - 2);
    }
}
```
