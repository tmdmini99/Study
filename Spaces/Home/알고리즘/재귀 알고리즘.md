
재귀 알고리즘(Recursive Algorithm)은 **함수가 자기 자신을 호출해서 문제를 푸는 방법**입니다. 작고 동일한 구조의 하위 문제들로 문제를 나누는 **분할 정복(Divide and Conquer)** 기법과도 관련이 깊습니다


## 재귀 알고리즘의 핵심 개념

1. **기저 조건(Base Case)**
    
    - 재귀 호출을 멈추기 위한 조건입니다.
        
    - 없으면 무한 반복(→ StackOverflowError 발생)
        
2. **재귀 호출(Recursive Case)**
    
    - 문제를 더 작게 쪼개어 자기 자신을 다시 호출합니다.


 팩토리얼 (Factorial)

```java
int factorial(int n) {
    if (n == 0) return 1;           // 기저 조건
    return n * factorial(n - 1);    // 재귀 호출
}
```
예: `factorial(3) = 3 * factorial(2) = 3 * 2 * 1 = 6`

피보나치 수열

```java
int fibonacci(int n) {
    if (n == 1 || n == 2) return 1;         // 기저 조건
    return fibonacci(n - 1) + fibonacci(n - 2);  // 재귀 호출
}
```

## 재귀의 동작 방식 (스택 구조)

재귀는 함수가 자기 자신을 호출할 때, **호출 정보를 스택에 저장**합니다.  
이 스택이 너무 깊어지면 `StackOverflowError`가 발생합니다.


## 재귀를 언제 쓰는가?

- **문제 구조가 반복적일 때**
    
- **트리/그래프 탐색**
    
- **백트래킹 (예: 퍼즐, 미로 찾기)**
    
- **하노이의 탑**, **조합/순열**, **분할 정복**


재귀의 단점

| 문제             | 설명                            |
| -------------- | ----------------------------- |
| 성능 저하          | 같은 계산을 반복할 수 있음 (→ 메모이제이션 필요) |
| Stack Overflow | 너무 많은 재귀 호출 시 스택 메모리 초과       |
| 디버깅 어려움        | 호출 흐름 추적이 어려울 수 있음            |

재귀 vs 반복

|항목|재귀|반복|
|---|---|---|
|코드 간결성|짧고 논리적|비교적 길어질 수 있음|
|성능|느릴 수 있음 (스택 사용)|일반적으로 빠름|
|사용 용도|트리 구조, DFS, 백트래킹 등|일반적인 루프 처리|
