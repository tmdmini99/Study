## timeToSec

이 함수는 **"mm:ss" 형식**의 문자열을 **초 단위의 정수**로 변환하는 역할

```java
private int timeToSec(String time) {
    String[] parts = time.split(":");  // ":"을 기준으로 "mm"과 "ss"를 분리
    return Integer.parseInt(parts[0]) * 60 + Integer.parseInt(parts[1]);  // mm * 60 + ss
}
```

### 동작 방식:

1. `time.split(":")`: `mm:ss` 형식의 문자열을 `":"` 기준으로 분리해서 배열로 만든다.
    
    - 예: "02:30" -> `["02", "30"]`
        
2. `Integer.parseInt(parts[0]) * 60`: 분을 초로 변환한다.
    
    - 예: `"02"` -> 2분 → 2 * 60 = 120초
        
3. `Integer.parseInt(parts[1])`: 초는 그대로 사용한다.
    
    - 예: `"30"` → 30초
        
4. 두 값을 더해서 최종적으로 **초 단위**의 값을 반환한다.
    
    - 예: `120초 + 30초 = 150초`




```java
class Solution {
    public String solution(String video_len, String pos, String op_start, String op_end, String[] commands) {
        int videoLenSec = timeToSec(video_len);
        int posSec = timeToSec(pos);
        int opStartSec = timeToSec(op_start);
        int opEndSec = timeToSec(op_end);
        
        // 오프닝 건너뛰기
        if (posSec >= opStartSec && posSec <= opEndSec) {
            posSec = opEndSec;
        }

        for (String cmd : commands) {
            if (cmd.equals("next")) {
                posSec += 10;
                if (posSec > videoLenSec) posSec = videoLenSec;
                else if (videoLenSec - posSec < 10) posSec = videoLenSec;
            } else if (cmd.equals("prev")) {
                posSec -= 10;
                if (posSec < 0) posSec = 0;
            }

            // 오프닝 건너뛰기
            if (posSec >= opStartSec && posSec <= opEndSec) {
                posSec = opEndSec;
            }
        }

        return secToTime(posSec);
    }

    // "mm:ss" → 초
    private int timeToSec(String time) {
        String[] parts = time.split(":");
        return Integer.parseInt(parts[0]) * 60 + Integer.parseInt(parts[1]);
    }

    // 초 → "mm:ss"
    private String secToTime(int sec) {
        int m = sec / 60;
        int s = sec % 60;
        return String.format("%02d:%02d", m, s);
    }
}
```
